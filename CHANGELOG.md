# Changelog

## 0.13.0

- Added persistent Wild NPC combat classes.
- Added weighted class rarity: 78% Classless, 8% Archer, 6% Knight, 5% Rogue, 3% Mage.
- Added persistent personalities: Balanced, Brave, Cautious, Aggressive, Tactical.
- Existing Wild NPCs receive a class/personality once when loaded if they do not already have one.
- Classless retains the existing mixed sword/ranged combat behavior.
- Archer now prefers ranged combat, maintains distance, kites pressure, and uses melee as a close fallback.
- Knight now commits to melee with increased health/armor and tighter spacing.
- Rogue now uses faster melee attacks, increased movement speed, and wider flanking movement.
- Mage now uses self-contained ranged magic attacks with vanilla spell effects and distance-control movement.
- Personality now changes retreat thresholds, combat confidence, help requests, spacing, and selected class timing.
- Mage does not require Iron's Spells 'n Spellbooks yet; Better Combat also remains optional.
- Reworked Developer Glasses into a compact four-tab HUD.
- Added configurable Developer Glasses tab-cycle keybind, default V.
- Added Overview, Combat, Survival, and Debug pages.
- Developer Glasses now display class and personality directly.

## 0.12.0

- Added a persistent 18-slot Wild NPC inventory.
- Migrated weapons and food into the real inventory.
- Updated cooking, chest storage, food choice, death drops, and Developer Glasses for inventory.

## 0.11.0

- Added emergency healing, full carried inventory drops, Zombification, and Zombie NPC conversion.
